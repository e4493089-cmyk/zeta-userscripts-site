Room Manager

  • 크리에이터 센터의 Room Manager 메뉴에 선택 삭제 기능 추가
  • 데이터 삭제 바로 아래에 빨간 글씨로 표시되며, 실행할 때만 플롯 카드에 체크박스 표시
  • 체크된 플롯은 순서대로 삭제하고 체크박스 선택 색상은 흰색으로 적용
  • PC/Android와 iOS 버전에 동일하게 적용
  • ZETA 기본 크리에이터 센터에서 플롯을 삭제해도 Room Manager 플롯 인덱스에서 즉시 제거
  • 플롯 전체 수집이 끝까지 정상 완료되면 현재 목록과 저장본을 비교해 이미 삭제된 플롯 데이터도 자동 정리
  • 대화방 나가기의 실제 DELETE 요청(/v1/rooms/<roomId>) 성공을 감지해 Room Manager 검색 인덱스에서도 즉시 제거
  • 실패한 방 직접 열어 이름 수집 버튼이 긴 실패 목록에서 눌리지 않도록 높이 고정
  • 삭제 직후 남아 있는 화면이 방을 다시 색인하지 못하도록 재수집을 차단하고, 전체 수집 완료 시 과거 삭제된 대화방 데이터도 자동 정리

대화 검색

  • 메시지 삭제 요청의 messagePointer를 감지해 해당 메시지부터 최신 메시지까지 검색 색인에서도 즉시 제거
  • 삭제 직후 남은 화면이 삭제된 메시지를 다시 색인하지 않도록 방지하고, 전체 색인 완료 시 과거 찌꺼기 정리도 유지
  • 검색창 우상단에 현재 방 색인을 TXT로 바로 내보내는 버튼 추가
  • 색인 TXT를 오래된 메시지부터 최신 메시지 순서로 저장하도록 정렬 수정
  • 모바일 상단 손잡이를 제거하고 내보내기·닫기 버튼을 회색 라운딩 버튼으로 정리

대화 추출 · OOC 숨기기

  • 대화 추출 메뉴·진행창·책갈피 구간 선택창이 카카오톡/커스텀 테마 색상 변수를 따라가도록 변경
  • 캡처 OOC 숨기기 버튼과 선택 표시도 동일한 테마 색상 변수를 사용하도록 변경
  • 테마가 없을 때는 기존 기본 색상을 그대로 사용
