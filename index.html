이름 가리기 설치
이 페이지의 설치 버튼은 GitHub Raw userscript 파일로 연결됩니다. Tampermonkey가 설치된 환경이라면 설치 화면이 열립니다. 코드만 보인다면 userscript 확장 기능이 켜져 있는지 확인하세요.

처음 설치하는 법

처음 한 번만 하면 됩니다.

Userscript 관리자 설치사용 중인 브라우저에 Tampermonkey 또는 호환 userscript 관리자를 설치합니다.
위 설치 버튼 누르기원하는 스크립트의 설치 버튼을 눌러 Tampermonkey 설치 화면을 엽니다.
Install / 설치스크립트를 설치하고 zeta-ai.io 페이지를 새로고침합니다.
업데이트스크립트에는 고정 @updateURL이 들어 있습니다. 새 버전이 올라오면 업데이트 확인을 통해 받을 수 있습니다.

사용법

설치 후에는 대부분 자동입니다.

카톡 테마Zeta 채팅방에 들어가면 자동 적용됩니다. 별도 버튼을 누를 필요가 없습니다.
캡처 이름 가리기평소에는 이름을 그대로 두고, 대화 캡처 모드/미리보기에서 검열 바를 적용합니다.
이름 일부도 가리기예: 표시 이름이 김제콩이면 김제콩과 제콩을 함께 가려 제콩아~ 같은 표현도 처리합니다.

FAQ

업데이트했는데 바로 반영이 안 돼요.

Tampermonkey의 userscript 업데이트 확인을 한 번 실행하고, Zeta 탭을 새로고침해 보세요. 자동 업데이트 확인은 즉시 실행되지 않을 수 있습니다.

테마랑 이름 가리기를 둘 다 설치해야 하나요?

아니요. 완전히 별개 스크립트라 원하는 것만 설치해도 됩니다.

이름 가리기가 평소 채팅도 바꾸나요?

캡처용으로 만들어져서 평소 채팅에서는 이름을 그대로 두고, 캡처 UI가 활성화됐을 때만 가리도록 동작합니다.

어떤 사이트에서 실행되나요?

두 스크립트 모두 메타데이터상 https://zeta-ai.io/*에서만 실행되며 @grant none입니다.

문제가 생기면 어디서 확인하나요?

GitHub 저장소에서 최신 파일을 확인하세요.
