대화 전체 저장

  • 전체 대화를 Markdown으로 저장하는 기능 추가
  • TXT 저장 옵션 추가
  • 책갈피 사이의 대화만 선택해서 저장하는 기능 추가
  • 책갈피 구간 탐색 및 불러오기 속도 개선
  • 정확한 메시지 위치를 기준으로 책갈피 구간을 찾도록 개선
  • 마지막 메시지가 빠지는 문제 수정
  • TXT 내보내기에서 내레이터 영역이 누락되거나 잘못 표시되는 문제 수정

대화 검색

  • 채팅방 안에서 지난 대화를 검색하는 스크립트 추가
  • 한 번 읽은 대화를 브라우저에 색인하여 이후 검색 속도 개선
  • 전체 대화 색인 과정 개선
  • 검색 결과 선택 시 해당 메시지 위치로 이동하는 기능 추가
  • Zeta의 메시지 커서를 이용해 오래된 메시지로 바로 이동하도록 개선
  • 이동 중 검색창 축소 및 진행 안내 UI 추가
  • 모바일 검색창 및 결과 화면 UI 개선
  • Room Manager와 메뉴 위치가 충돌하던 문제 수정

Room Manager

  • 플롯명뿐 아니라 캐릭터명·제작자명으로 검색할 수 있도록 확장
  • 채팅방 안에서도 별명을 설정할 수 있도록 변경
  • 별명 설정창이 사용 중인 테마를 따라가도록 개선
  • Android/PC와 iOS용 Room Manager를 분리하고 각각 최적화
  • 대화방 및 플롯 전체 수집 방식 개선
  • 이미 수집한 정보를 불필요하게 다시 읽지 않도록 개선
  • 누락된 캐릭터명·제작자명 보완 방식 개선
  • 삭제되거나 정보가 부족한 플롯의 이름 수집 경로 개선
  • 수집 실패 시 방 이름·주소·실패 이유를 확인할 수 있도록 개선
  • 수집 완료 결과를 인앱 팝업으로 표시하고 수집 중 즉시 중단 가능하도록 개선
  • 대량 수집 중 메모리 사용량 및 Out of Memory 문제 완화
  • 수집 완료 후 무한 새로고침 및 반복 재시작 문제 수정
  • 방 목록 스크롤 끊김 개선
  • 불필요한 반복 처리 및 죽은 코드 정리
  • 화면 이동 감지를 폴링 방식에서 History 이벤트 방식으로 변경

카카오톡 테마

  • 피스 충전 바텀시트와 충전 UI를 밝은 테마에 맞게 수정
  • 꿈 관련 화면과 확인 팝업의 테마 적용 개선
  • 채팅 배경에 따라 UI 글자 대비가 자동으로 맞도록 개선
  • 삭제 모드에서 남아 있던 흰색 배경 및 상태 영역 수정
  • 일부 화면에서 글자가 보이지 않던 대비 문제 수정
  • 불필요하게 중복된 스타일 및 죽은 코드 정리

전체화면

  • 메시지 수정창을 크게 열었을 때 전체화면 버튼이 편집 UI 위로 올라오던 문제 수정

북마클릿

  • ZETA Tools Launcher 추가
  • 여러 북마클릿을 각각 실행하지 않고 런처 하나에서 원하는 도구를 선택해 실행할 수 있도록 추가
  • 런처에서 불러오는 도구는 최신 스크립트 기준으로 자동 업데이트되도록 구성

기타

  • 스크립트 내부 자동 업데이트 URL 정리
  • 하드코딩된 일부 값을 자동 감지 방식으로 변경
  • README를 현재 공개 스크립트 기준으로 정리
  • 설치 방법, 업데이트 방식, 주의사항 및 면책 안내 추가
