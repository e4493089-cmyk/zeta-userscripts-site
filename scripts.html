빠른 설치법

처음 한 번만 userscript 관리자를 준비하면 이후에는 설치 버튼만 누르면 됩니다.

1Tampermonkey 준비현재 브라우저에서 userscript를 실행할 수 있게 확장/앱을 설치합니다.
2원하는 스크립트 설치아래 카드에서 설치를 누르고 Tampermonkey의 Install을 확인합니다.
3Zeta 새로고침zeta-ai.io를 다시 열거나 새로고침하면 자동으로 적용됩니다.
팁: 네 스크립트는 서로 별개라서 전부 설치할 필요 없습니다. 카톡 테마 + 캡처 이름 가리기 + Room Manager를 기본으로 쓰고, Fullscreen은 필요할 때만 켜도 됩니다.

Zeta KakaoTalk Theme · v3.48.6

자동 업데이트

캡처 이름 가리기

Zeta Capture User Mask · v0.2.1

자동 업데이트
Tampermonkey에 설치
무엇을 가리나요?캡처 모드와 미리보기에서 실제 유저 이름을 검열 바로 표시합니다. 예: 김제콩 → 마스킹, 제콩아~ 같은 이름 부분도 처리.
평소 채팅은?평소 대화 화면은 그대로 두고 캡처 관련 화면에서만 가리도록 만든 스크립트입니다.

Room Manager

Zeta Room Manager · v0.1.5

자동 업데이트
Tampermonkey에 설치
별명 & 검색대화방과 비공개 플롯에 로컬 별명을 붙이고 원래 이름 또는 별명 어느 쪽으로든 검색할 수 있습니다.
별명 편집대화방을 길게 눌러 나오는 기존 액션 영역에 ‘별명 변경’을 추가해 목록을 깔끔하게 유지합니다.
저장 위치: 별명은 Zeta 서버 이름을 바꾸는 게 아니라 현재 브라우저의 로컬 저장소에만 저장됩니다.

Fullscreen

Zeta Fullscreen · v0.1.1

자동 업데이트
Tampermonkey에 설치
동작화면의 작은 ⛶ 버튼을 눌러 브라우저 Fullscreen API를 실행합니다. 진입 후 버튼은 숨고, 전체화면이 풀리면 다시 나타납니다.
알아둘 점모바일 브라우저 판단에 따라 주소창뿐 아니라 폰 자체 상태바/내비게이션바까지 함께 숨겨질 수 있습니다.
브라우저 제한: 웹 스크립트로 Edge 주소창/하단바만 골라 영구 숨기는 것은 불가능합니다. 이 기능은 브라우저가 허용하는 전체화면 동작을 사용하는 방식입니다.
