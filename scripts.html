ROOM TOOLS · AOS / PC

Room Manager

v0.5.2

자동 업데이트

AOS/PC에서 대화방과 비공개 플롯에 별명을 붙이고, 플롯명·캐릭터명·제작자명으로 검색합니다.

별명 바꾸기대화방을 길게 누르고 ‘별명 변경’을 선택합니다.
저장별명과 수집 정보는 현재 브라우저에만 저장됩니다.
수집 팁: 먼저 만들기 → 비공개에서 전체 수집을 실행하면 캐릭터명과 제작자명을 빠르게 모을 수 있습니다. 이후 대화방에서 일반 전체 수집을 실행하면 이미 확인한 정보와 중복 플롯을 건너뜁니다. 다시 전체 수집은 저장된 수집 데이터를 지우고 처음부터 확인할 때만 사용하세요.
※ 주의 (저장)
별명과 수집 인덱스는 이 브라우저 안에만 저장됩니다. 서버에 올라가지 않고 기기끼리 동기화되지도 않습니다.
브라우저에서 인터넷 사용 기록 삭제 → 쿠키 및 사이트 데이터를 삭제하면 함께 지워집니다.
저장 공간이 부족하면 브라우저가 오래된 사이트 데이터부터 버립니다.
보관하거나 다른 환경으로 옮기려면 메뉴의 백업(내보내기)을 사용하세요.
zeta-room-manager.user.js

Room Manager (iOS)

v0.3.6

자동 업데이트

별명 바꾸기대화방을 왼쪽으로 밀고 ‘별명’을 누릅니다.
iPhone 설치Stay에서 + → Link로 스크립트 주소를 추가합니다.
수집 팁: 먼저 만들기 → 비공개에서 전체 수집을 실행하면 캐릭터명과 제작자명을 빠르게 모을 수 있습니다. 이후 대화방에서 일반 전체 수집을 실행하면 이미 확인한 정보와 중복 플롯을 건너뜁니다. 다시 전체 수집은 저장된 수집 데이터를 지우고 처음부터 확인할 때만 사용하세요.
※ 주의 (저장)
별명과 수집 인덱스는 이 브라우저 안에만 저장됩니다. 서버에 올라가지 않고 기기끼리 동기화되지도 않습니다.
브라우저에서 인터넷 사용 기록 삭제 → 쿠키 및 사이트 데이터를 삭제하면 함께 지워집니다.
저장 공간이 부족하면 브라우저가 오래된 사이트 데이터부터 버립니다.
보관하거나 다른 환경으로 옮기려면 메뉴의 백업(내보내기)을 사용하세요.
※ 주의 (iOS)
사파리는 7일 동안 제타에 들어오지 않으면 저장한 내용을 지웁니다.
iOS의 크롬·파이어폭스도 사파리 엔진을 쓰므로 똑같이 적용됩니다.
날아가도 백업(내보내기) 파일이 있으면 불러오기로 되돌릴 수 있습니다.
