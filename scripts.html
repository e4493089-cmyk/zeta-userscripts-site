기능·사용 방법

사용 방법

이름 가리기를 실행한 뒤 제타의 대화 캡처를 여세요. 실제 대화 내용이나 서버 데이터는 변경하지 않습니다.

Room Manager

v0.23.92

대화방과 비공개 플롯의 별명·검색·수동 전체 수집·백업을 관리합니다.

기능·사용 방법

주요 기능

  • 별명 관리대화방과 비공개 플롯에 브라우저 안에서만 쓰는 별명을 붙이거나 원래 이름으로 되돌립니다. 제타 서버의 이름은 변경하지 않습니다.
  • 이름 검색저장된 원래 이름·별명·플롯명·캐릭터명·제작자명으로 대화방이나 비공개 플롯을 찾습니다.
  • 수동 전체 수집대화방 목록 또는 만들기 → 비공개에서 메뉴를 열어 실행합니다. 평소 목록을 보거나 대화할 때에는 방 정보를 자동 분석하지 않습니다.
  • 일반 수집·다시 수집대화방의 ‘일반 전체 수집’은 기존 정보와 중복 플롯을 활용합니다. ‘다시 전체 수집’은 이전 수집 잠금을 무시하고 정보를 재확인합니다. 별명을 초기화하는 기능은 아닙니다.
  • 진행·중지·실패 확인진행 중 수집 개수와 상태를 확인하고 중지할 수 있습니다. 결과에서 실패한 방을 확인하고, 지원되는 경우 직접 열어 이름을 다시 수집할 수 있습니다.
  • 백업·복원메뉴의 ‘내보내기’로 별명과 수집 정보를 JSON 파일에 저장하고, ‘불러오기’로 백업을 가져옵니다.
  • 도구 데이터 삭제메뉴의 ‘데이터 삭제’는 Room Manager의 별명과 수집 데이터를 지웁니다. 제타의 실제 대화방이나 플롯을 삭제하는 기능과는 다릅니다.
  • 비공개 플롯 선택 삭제만들기 → 비공개에서 ‘선택 삭제’를 누르고 플롯을 고른 뒤 삭제합니다. 이 기능은 제타의 실제 플롯을 삭제하며 되돌릴 수 없습니다.

사용 방법

대화방 목록에서는 길게 누르기 메뉴의 ‘별명 변경’을 사용합니다. 대화방 안에서는 메뉴의 ‘별명’, 비공개 플롯 목록에서는 각 항목의 ‘별명’으로 수정할 수 있습니다. 수집·백업은 목록 상단의 Room Manager 메뉴(⋯)에서 실행하세요.

참고·보관 시 주의사항
수집 순서: 먼저 만들기 → 비공개에서 전체 수집을 실행하고, 이후 대화방 목록에서 일반 전체 수집을 실행하세요. 새 방이나 변경된 이름을 검색에 넣으려면 수동 수집을 다시 실행합니다. 수집은 현재 제타 화면에서 진행하므로 완료될 때까지 해당 화면을 유지하세요.
※ 주의 (저장)
별명과 수집 인덱스는 이 브라우저에만 저장됩니다. 서버에 저장되지 않으며 기기 간 동기화도 되지 않습니다.
인터넷 사용 기록 삭제 → 쿠키 및 사이트 데이터를 지우면 함께 삭제됩니다.
저장 공간이 부족하면 오래된 사이트 데이터가 정리될 수 있습니다.
보관하거나 다른 환경으로 옮기려면 메뉴의 백업(내보내기)을 사용하세요.

대화 전체 저장

v0.3.12

전체 대화 또는 두 책갈피 사이의 대화를 MD·TXT 파일로 저장합니다.

기능·사용 방법

주요 기능

  • 전체 대화 수집현재 화면에 없는 과거 대화도 스크롤로 불러와 모으고, 오래된 대화부터 최신 대화 순서로 정리합니다.
  • 책갈피 구간서로 다른 두 책갈피를 시작·끝으로 골라 해당 메시지를 포함한 구간만 저장합니다. 구간 선택에는 책갈피가 두 개 이상 필요합니다.
  • Markdown메시지를 나·캐릭터·서술로 구분하고 지문·대사와 이미지 주소를 기록합니다. 이미지 파일 자체를 내려받는 방식은 아닙니다.
  • 텍스트화자의 실제 이름과 *지문* 형식으로 읽기 쉬운 TXT를 만듭니다.
  • 진행·취소수집 진행 상황을 확인하고 취소할 수 있습니다.

사용 방법

대화방에서 ‘대화 내보내기’를 누르고 전체 · Markdown, 전체 · 텍스트 또는 책갈피 구간을 선택하세요. 수집 중에는 대화방을 닫거나 다른 방으로 이동하지 마세요.

참고·보관 시 주의사항
참고: 대화 수집 중에는 채팅방을 닫지 마세요.

대화 검색

v0.3.5

현재 대화방의 지난 메시지와 상태창을 검색하고, 결과 위치로 이동합니다.

기능·사용 방법

주요 기능

  • 대화방 안에서 검색대사·지문을 검색하고 결과를 누르면 해당 메시지로 이동하며 위치를 강조합니다.
  • 새 메시지 자동 색인화면에 불러온 메시지와 변경된 본문을 브라우저에 색인합니다. 관련 없는 화면 클릭은 다시 색인하지 않습니다.
  • 이 방 전체 색인하기아직 불러오지 않은 오래된 대화까지 검색하려면 전체 색인을 실행하세요. 진행 중 중지할 수 있습니다.
  • 상태창 검색제타 기본 상태창의 날짜·시간·장소·기분·속마음 등과 코드블록·표 형태의 상태창도 함께 색인합니다.
  • TXT 내보내기검색창 우상단의 내보내기 버튼으로 현재 방에 저장된 색인을 TXT로 저장합니다. 아직 색인하지 않은 메시지는 포함되지 않습니다.
  • 삭제 반영제타에서 실제로 삭제한 메시지는 감지 가능한 삭제 요청에 따라 검색 색인에서도 정리합니다.

사용 방법

대화방 메뉴(⋮) → 대화 검색에서 검색어를 입력하세요. 오래된 대화가 나오지 않으면 ‘이 방 전체 색인하기’를 실행합니다. 색인은 이 브라우저에만 저장됩니다.

참고·보관 시 주의사항
상태창 추가: 기존 대화는 업데이트 후 이 방 전체 색인하기를 다시 실행하세요.
※ 주의 (저장)
색인은 이 브라우저 안에만 저장됩니다. 서버에 올라가지 않고 기기끼리 동기화되지도 않습니다.
브라우저에서 인터넷 사용 기록 삭제 → 쿠키 및 사이트 데이터를 삭제하면 함께 지워집니다.

대화방에 전체화면 전환 버튼을 추가합니다.

기능·사용 방법

주요 기능

  • 전체화면 전환버튼을 누르면 전체화면으로 전환하고, 전체화면에서 다시 누르면 원래 화면으로 돌아옵니다.
  • 대화방 버튼 배치액션 버튼이 있으면 그 위쪽에, 없으면 입력창 위의 버튼 영역에 표시합니다.
  • 대화 수정 시 숨김확장된 대화 수정 입력창이 열리면 버튼을 잠시 숨겨 편집을 방해하지 않도록 합니다.

사용 방법

대화방에서 전체화면 버튼을 누르세요. 브라우저의 전체화면 지원 여부에 따라 동작이나 상태바 표시가 달라질 수 있습니다.

참고·보관 시 주의사항
모바일: 브라우저에 따라 휴대폰 상태바나 내비게이션바까지 숨겨질 수 있습니다.
