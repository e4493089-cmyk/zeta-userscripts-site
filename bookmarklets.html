북마크 하나로 실행.

Tampermonkey를 쓰기 어려운 브라우저에서 사용합니다. 아래 코드를 북마크 URL에 한 번 저장해두면, Zeta 페이지에서 북마크를 누를 때마다 GitHub의 최신 스크립트를 불러옵니다.

모바일 추천: 테마 + 이름 가리기의 코드 복사를 누른 뒤 북마크 URL에 붙여넣으세요. 새로고침하면 효과가 풀리므로 다시 눌러야 합니다.

모바일에서 넣는 법

  1. 아무 웹페이지를 북마크로 하나 저장합니다.
  2. 북마크 편집에서 이름을 Zeta 테마 같은 식으로 바꿉니다.
  3. URL/주소 칸을 전부 지우고 javascript:... 코드를 붙여넣습니다.
  4. Zeta 채팅방을 열고 해당 북마크를 누릅니다.
  5. 새로고침하거나 페이지가 다시 로드되면 북마클릿을 다시 눌러주세요.

북마클릿 코드는 고정이지만 실제 실행 코드는 GitHub Raw에서 매번 최신 버전을 불러옵니다. 스크립트가 업데이트돼도 북마클릿을 다시 만들 필요는 없습니다.
