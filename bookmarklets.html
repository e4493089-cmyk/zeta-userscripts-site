북마크 하나로
필요할 때 실행.

북마크 주소 칸에 JavaScript 코드를 저장해두고 Zeta 페이지에서 눌러 실행합니다. 북마클릿 자체는 고정이지만 실제 기능은 GitHub의 최신 userscript를 매번 불러옵니다.

모바일에서 제일 쉬운 방법: 아래에서 ‘코드 복사’ → 브라우저 북마크 하나 만들기 → 북마크 편집 → URL/주소를 전부 지우고 붙여넣기 → Zeta에서 그 북마크 실행.

설치 순서

브라우저마다 북마크 편집 위치만 조금 다르고 원리는 같습니다.

1아무 페이지를 북마크Zeta든 다른 페이지든 일단 북마크 하나를 만듭니다.
2URL을 코드로 교체북마크 편집에서 주소를 지우고 복사한 javascript:... 전체를 붙여넣습니다.
3Zeta에서 북마크 실행효과는 새로고침하면 풀릴 수 있으므로 필요할 때 다시 눌러주세요.
